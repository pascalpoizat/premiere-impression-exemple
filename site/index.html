Le projet

La préparation d'un entretien est éclatée entre les sites d'emploi, l'agenda, les révisions et les applications de transport, et beaucoup d'étudiants n'ont pas de tenue adaptée. PremièreImpression réunit tout autour d'un objet central, la candidature et son entretien, et calcule des décisions plutôt que de stocker des données : quelles compétences l'annonce attend, quels vêtements prêtés par d'autres étudiants vont réellement, quoi réviser, à quelle heure partir.

Architecture

Front web (HTML, JavaScript natif) → API REST (Spring Boot 4) → back Java 21 en architecture hexagonale, un module par domaine (candidature, tenue) → PostgreSQL, schéma versionné par Flyway. Plus de 200 tests (unitaires, propriétés, intégration, architecture) et une release automatique à chaque tag.

Part IA / part humaine

Part de l'IA générative déclarée par compétence, comparée aux plafonds fixés par l'équipe. Sur cet exemple, l'IA dépasse les plafonds sur tous les axes : c'est précisément ce qu'une équipe d'étudiants doit éviter sur le haut niveau.
